# 这个文件夹是干什么的

**`materials/` 才是程序真正读的目录。** 这里放的是示例，让你知道该写成什么样。

## 怎么开始

1. 把整个 `materials.example/` 复制一份、改名成 `materials/`
2. 把里面的假内容换成你自己的
3. 跑程序

```
materials.example/  →  复制改名  →  materials/
```

## 文件怎么组织

程序会**按文件名排序**读 `materials/` 下所有 `.md` 和 `.txt`，拼进给模型的 prompt。
所以**文件名前面的数字决定先后**，`01-` 排最前面。

建议按「一段经历 / 一个作品」一个文件：

```
materials/
├── resume.txt              简历纯文本（用 materials_build.py 从 PDF 生成）
├── 01-某公司实习.md         当前/最近的一段
├── 02-上一家公司.md
├── 03-某某作品.md
└── 04-更早的经历.md
```

## 写的时候记两条

**① 写"为什么"，不只写"做了什么"。**
面试官不会问"你用了什么技术"，会问"你为什么这么做"。把设计取舍、踩过的坑写进去，
模型答出来的东西才有底气。

**② 没把握的地方明确标出来。**
比如某个数字你自己也说不清口径，就写：

```markdown
## ⚠️ 面试前必须说清楚
- 简历上"通过率提升 40 个百分点"的口径：对照组是什么、怎么统计的。
```

模型看到这种标记会主动回避那个数字，不会替你编一套口径 —— 这在面试里是保命的。

## 还有两个约定

- **`resume.txt` 别手改**，用 `materials_build.py` 从简历 PDF 自动生成
- **没写进素材的具体事实，模型不会编**（prompt 里有铁律）。所以素材越全，答得越实。
