# interview-assistant

> 线上面试时，实时把面试官的问题转成一份「能直接照着说出口」的参考答案，贴在屏幕角落的悬浮窗里。

它**同时听两边**：

- **面试官的声音**（抓系统声音）→ 转写 → 判断这一句到底是不是真问题 → 是就给答案
- **你的声音**（抓麦克风）→ 转写 → 只用来理解上下文。**你说话的时候它完全安静**，不闪、不弹

答案不是通用模板，是从你自己的简历和经历素材里长出来的 —— 面试官往下追问也接得住。

---

## 它是怎么判断的

面试官的话不全是问题。大量是寒暄、铺垫、回应、玩笑、念稿：

```
[面试官] 好的，那我们今天再聊一下。你帮我先介绍一下自己吧。
                ↓
        本地粗筛（不发模型，零成本）
                ↓
   「嗯」「OK」「好的」「明白了」这类 → 直接跳过
                ↓
        发一次模型，模型回三种标记之一
                ↓
┌─────────┬──────────────────────────────┬─────────────────┐
│  [Q]    │ 面试官问了一个新问题          │ 刷新窗口，出新答案 │
│  [F]    │ 在追刚才那个话题往下问        │ 原答案留着，下面接补充 │
│ [SKIP]  │ 不是问题（寒暄/铺垫/玩笑/听不清）│ 窗口一动不动      │
└─────────┴──────────────────────────────┴─────────────────┘
```

**关键设计**：判 `[SKIP]` 的时候窗口**完全不动**。你正在看的上一题答案不会被抢走 ——
这是这类工具最容易做砸的地方。

窗口长这样：

```
参考答案   识别中…              ‹ 2/7 ›        [结束] [✕]
🎯 面试官问的是：你实习是在哪儿
────────────────────────────────────────────
我之前在字节做招聘实习，主要负责技术岗…

（——— 追问：这两段都是吗 ———）      ← [F] 时接在原答案下面

透明度 ────────●─────────
```

## 环境要求

| | |
|---|---|
| 系统 | **Windows 10/11**（靠 WASAPI loopback 抓系统声音，其他系统不行） |
| Python | 3.11 或更高 |
| 显卡 | 有 NVIDIA GPU 会快很多，没有也能跑（自动回退 CPU） |
| 网络 | 需要能访问 `api.deepseek.com` |

## 安装

### 1. 装依赖

```bat
setup.bat
```

或者手动：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 填 API Key

复制 `.env.example` 为 `.env`，填上你的 DeepSeek Key（去 [platform.deepseek.com](https://platform.deepseek.com) 拿）：

```
DEEPSEEK_API_KEY=sk-你的key
```

> `.env` 已在 `.gitignore` 里，不会被提交。**别把 key 写进任何代码文件。**

### 3. 放你的素材

```bat
xcopy /E /I materials.example materials
```

然后编辑 `materials\` 里的文件，换成你自己的。详见 [materials.example/怎么改.md](materials.example/怎么改.md)。

简历是 PDF 的话：

```bat
.venv\Scripts\python materials_build.py "路径\到\你的简历.pdf"
```

> **素材是这个工具的全部价值来源。** 写得越细（尤其是"为什么这么做"和踩过的坑），
> 答出来的东西越有底气。没写进素材的具体事实，它不会编。

### 4. 首次运行

第一次启动会自动下载 faster-whisper 的语音模型（几个 G，走 `hf-mirror.com` 镜像）。
耐心等一次，之后就本地缓存了。

## 跑之前先自检音频

**这一步别省。** 面试官的声音从哪个耳机出来，程序就跟哪个设备 —— 跟错了就一条都录不到。

先戴好耳机、确认它是 Windows 的默认播放设备，然后：

```bat
.venv\Scripts\python _audio_devices.py test
```

它会自己放一段「嘟——」，然后告诉你结果。要看到：

```
✅ [40] 耳机 (XXX) [Loopback] 听到了测试音 （就是程序在用的）
```

看到 ❌ 或者你没听见嘟声，先把音频设备弄对，再看别的。

## 运行

```bat
run.bat
```

会弹出两个窗口：**黑的控制台**（别关，出问题全靠它）+ **设置窗**。

设置窗填两栏：

| | |
|---|---|
| 岗位名称 | 用在存档文件名上 |
| 岗位 JD | 招聘页上的 JD 全文。**留空则用 `jd.txt`** |

> 💡 **JD 框里还可以再加一段"公司速查"**（公司做什么、规模、最近动态）。
> 不写的话，被问到"你对我们公司有什么了解"，它只能从 JD 内容反推 —— 容易说错。
> 详见 [materials.example/怎么改.md](materials.example/怎么改.md)。

### 热键

| 键 | 干什么 |
|---|---|
| **F1** | 换一版答案。**判定错了（该出答案却没出）也按这个** —— 它不再问模型要不要答，直接出 |
| **F2** | 换个角度再答一版 |
| **F3** | 隐藏 / 恢复窗口 |
| **F5** | 结束本场并保存记录 |
| **F4** | 退出程序（退出前也会存一份） |

改热键：编辑 `config.json`，改完重启生效。

### 什么时候**不会**出答案（这是设计，不是坏了）

- 面试官在寒暄 / 介绍团队 / 讲自己的经历 → 他本来就没问你什么
- 面试官在回应你刚才说的
- **你正在说话** → 完全安静，不打扰你
- 转写出来是乱码、听不清
- 被问到你素材里没有的具体事实 → 它会说"记不准"而不是编

## 出问题了看哪

| 症状 | 先查 |
|---|---|
| **一个答案都不出** | 控制台有没有连续的 `[面试官] xxx`。**没有 = 声音没进来** |
| 控制台没有任何 `[面试官]` | 窗口上应该已经弹了 ⚠ 警告。检查耳机是不是默认播放设备，连好，**重开一次** |
| 答案答非所问 | 看蓝色问题行抓的是哪句，抓错了按 F1 |
| 窗口不见了 | F3 |
| 程序没反应 | 控制台里有没有红色报错 |

程序**每 3 秒检查一次默认输出设备**，中途换耳机会自己跟上（窗口会显示"已跟随到新的音频设备"）。

## 记录在哪

`sessions\` 文件夹，文件名是 `岗位名_日期时间`：

| | |
|---|---|
| `.txt` | **边聊边写**，完整对话，永远不会丢 |
| `.md` | **只有按 F5 或点「结束」才生成**，含 JD + 最后一版答案 |

`sessions/` 已在 `.gitignore` 里 —— **里面是你的真实面试内容，别提交、别外传。**

## 项目结构

```
├── main.py              入口：起采集/ASR/LLM/热键线程 + 串起 Qt 窗口
├── capture.py           双通道音频采集 + VAD 分句（含非阻塞读取、设备跟随）
├── asr.py               faster-whisper 转写（含静音幻觉过滤）
├── llm.py               组 prompt + 调 DeepSeek 流式生成
├── transcript.py        对话记录 + 存档
├── ui.py                设置窗 + 答案悬浮窗
├── materials_build.py   从简历 PDF 生成 materials\resume.txt
├── _audio_devices.py    音频通道体检（跑之前先自检用）
├── config.json          热键配置
│
├── test_gate.py         自动测试：判定/解析/窗口状态机（不花钱，推荐常跑）
├── test_live_prompt.py  真实打 API 验证模型输出格式（会花钱）
├── test_m1~m4.py        早期里程碑的手动测试（要人肉看窗口）
│
├── materials.example/   素材模板（复制改名成 materials\ 再用）
└── sessions/            面试存档（已 gitignore）
```

## 已知限制

- **只在 Windows 上能用**。抓系统声音靠 WASAPI loopback，macOS / Linux 得换方案。
- **是转写，不是实时字幕**。一句话说完、静音 1.2 秒才判定说完，加上转写和生成，
  从面试官闭嘴到你看到答案大约 **3-5 秒**。
- **转写质量取决于环境**。有回声、有杂音、说得含糊，都会转错。名字、专有名词尤其容易错。
- **素材里没有的具体事实，它不会说**（这是刻意的）。所以素材要自己写全。
- 第一次运行要下几个 G 的模型。

## 使用须知

这类工具在不少公司**属于明确禁止的行为**（很多 AI 面试开场就会声明"发现作弊取消资格"）。
不同公司、不同面试形式的规则差别很大，**请自行确认你参加的那一场是否允许**，后果自负。

如果只是想练面试、或者面试后复盘，这个工具同样好用，而且完全没有这方面的顾虑 ——
把 `sessions\` 里生成的 `.md` 拿出来对着重练就行。
